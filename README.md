# Sprint-Analyse

Bewegungsanalyse für Sprint und 400 m Hürden aus Videos: Pose-Erkennung, Winkel, fliegende Zeiten, Hürde-zu-Hürde-Zeiten und Laufvergleich.

**Online:** https://legummi.github.io/sprint-analyse/

Läuft komplett im Browser (MediaPipe Pose Landmarker). Videos werden nicht hochgeladen. Gespeicherte Läufe bleiben lokal im jeweiligen Browser; zum Teilen den JSON-Export nutzen.
